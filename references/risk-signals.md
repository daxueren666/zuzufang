# 租房风险信号分类法与关键词词典

> 本文件是 clean.py 风险粗分类的**正本**：lexicon.py 的词典从此同步，改词典先改本文件。
> 8 个维度与 SKILL.md 中 analysis.json 的 dimensions 固定 8 项一一对应。

## 使用规则

1. **clean.py（脚本粗分类）**：对 title + content + top comments 做子串匹配（全小写化），命中任一关键词即打该维度 tag；一条帖可叠加多个 tag。
2. **Claude（语义复核）**：粗分类只是候选。分析 cleaned JSON 时必须读上下文剔除否定/疑问/转述误命中（如"从来没漏过水""会不会有蟑螂啊"不算命中），并补充脚本无法识别的同义表达。
3. 脚本不处理否定语义，因此**脚本 tag 数量只用于 coverage 统计，不得直接等于 findings 数量**。

## 严重度分级（severity）

| 级别 | 判定标准 | 典型场景 |
|---|---|---|
| 高 | 资金损失风险、人身安全风险、健康风险 | 押金不退/被骗定金、中介跑路、断水断电赶人换锁、凶宅、治安案件、严重霉变虫害 |
| 中 | 居住体验实质受损、可预期纠纷 | 长期漏水维修慢、临街噪音、商水商电高额账单、物业不作为、通勤超1小时、虚假图片 |
| 低 | 个别抱怨、主观不适、影响有限 | 单次邻居吵、水压偏小、公交班次少、个别态度差 |

## 置信度分级（confidence）

| 级别 | 判定标准 |
|---|---|
| 高 | 多平台多条独立帖相互印证，或有高赞评论补充佐证 |
| 中 | 单平台多条帖子，或单帖但评论区多人附和 |
| 低 | 单帖孤证、发帖时间超过2年、疑似广告/情绪宣泄帖 |

## 广告贴识别（clean.py 过滤正本）

特征词：
拎包入住、随时看房、免中介费、免押金、零押金、精装公寓、品质公寓、品牌公寓、管家、管家服务、专属管家、真房源、房源编码、预约看房、咨询vx、加vx、加V、加微信、私信我、评论区留言、戳我、联系电、电话1、特价房、急租、秒杀、直降、限时优惠、全网最低、租房福利、优惠活动、首月免租、免房租、可短租可长租、独立卫生间带窗户（公寓文案组合词）、自如、泊寓、冠寓、朗诗寓、魔方公寓、城家、相寓

判定规则：

1. 命中 2 个及以上特征词 → 标记 `ad: true`。
2. 命中 1 个特征词 + 正文含联系方式（11位手机号、"vx/微信/QQ+号"诱导）→ 标记 `ad: true`。
3. `ad: true` 的帖子：尽调/推荐/选址模式（意图 A/B/C）**剔除**；找房源模式（意图 D）**保留**并标注"疑似中介广告"，排序靠后。

## clean.py 对接要求

- 词典同步自本文件；tag 名用上表映射（quality / landlord_agent / deposit_fee / fake_listing / noise / property / safety / commute_facility）。
- is_listing 判定（意图 D 用）：命中"转租、直租、合租、整租、无中介、个人转租、房东直租、室友、次卧、主卧、招租、出租"任一词，且（含价格数字或户型词"室/厅/平/主卧/次卧"）→ `is_listing: true`，并抽取 `price_hint`（如"2600/月"）与 `room_hint`（如"主卧""两室一厅"）。
- 每条 cleaned 记录需保留 `ad`、`is_listing`、`risk_tags`（数组）、`top_comments`（点赞排序前 N 条）字段，供 Claude 语义分析使用。
