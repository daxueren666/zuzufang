# 租房避坑自查清单

> 用途：意图 E（租房咨询）的知识库；尽调数据不足（有效帖 <3 条）时的降级输出内容。
> 四阶段：看房前 / 看房时 / 签合同前 / 入住后与退租。引用时注明阶段与条目编号。

## 一、看房前（信息筛选）

- [ ] 核实价格真实性：明显低于同片区行情 20% 以上的，先按虚假房源处理，别当捡漏。
- [ ] 对小区名/中介名跑本 skill 尽调（意图 A），看口碑帖里的高频坑。
- [ ] 中介公司背景：查 12315 投诉公示、裁判文书网搜"公司名+房屋租赁纠纷"。
- [ ] 确认出租方身份：要求出示房产证（或不动产权证）+ 身份证，两证名字必须一致。
- [ ] 二房东必须出示：原始租赁合同 + 房东同意转租的书面授权，缺一不租。
- [ ] 识别广告贴特征：拎包入住/免押金/管家服务/加微信看房，多为公寓中介投放，个人直租信息优先。
- [ ] 用地图街景和卫星图查周边：是否临街、挨高架/铁路、垃圾站、加油站、殡葬场所距离。
- [ ] 通勤实测：工作日早高峰查地图公共交通方案，把步行接驳时间也算进去，往返超 2 小时要慎重。
- [ ] 算清总预算：房租 + 水电物业网 + 中介费摊销，建议不超过月收入三分之一。
- [ ] 拒绝租金贷：任何"贷款付租金""年付有折扣"引导直接放弃，长租公寓暴雷前都是这个套路。

## 二、看房时（实地核验）

- [ ] 打开所有水龙头测水压，冲一次马桶看下水速度和返味。
- [ ] 查霉斑和墙皮：墙角、窗边、家具背后、窗帘后面，南方重点看回南天痕迹。
- [ ] 开窗听噪音：临街、高架、铁路、夜市；有条件晚上再来看一次。
- [ ] 测手机信号（每个房间），问清宽带运营商和入户方式、网费谁出。
- [ ] 逐个试电器：空调制冷制热、热水器出热水速度、洗衣机、燃气灶、抽油烟机。
- [ ] 检查门窗密封与锁具，问清入住后能否换锁芯或改密码锁。
- [ ] 看公共区域：楼道卫生、电梯运行、垃圾桶位置、消防通道是否被占，这是物业水平的直观信号。
- [ ] 问邻居或楼下小店：小区治安、停水停电频率、物业口碑、晚上吵不吵。
- [ ] 确认车位/电动车充电桩/快递柜位置和收费。
- [ ] 看采光：当下时间 + 问清几点太阳进屋，注意前排楼栋遮挡。
- [ ] 全屋拍照录像：家具家电清单和已有破损处，开日期水印，作为退租对比证据。

## 三、签合同前（条款审查）

- [ ] 合同甲方必须是产权人；不一致时要求完整的委托/转租授权链条并留复印件。
- [ ] 押金条款写明：金额、退还条件、退还时限（如"退租验收后 7 日内无息退还"）。
- [ ] 扣款标准量化：卫生费、折旧费、维修责任划分，不接受"视情况扣除"。
- [ ] 租期内不涨租写进合同；提前退租违约金比例、转租是否允许及费用写明。
- [ ] 水电燃气单价写明：确认民水民电，商水商电按商业价计费的房子要重新算总成本。
- [ ] 物业费、取暖费、网费、车位费由谁承担逐项写明。
- [ ] 家具家电清单作为合同附件，逐项标注品牌和现状（新旧/破损）。
- [ ] 维修责任划分：自然损耗（水管老化、电器故障）由谁修、报修响应时限。
- [ ] 租金支付对象 = 合同甲方本人账户，拒绝第三方收款、拒绝现金无凭证。
- [ ] 逐条读违约条款和"其他约定"，空白栏划线作废，防止事后加字。
- [ ] 所有口头承诺（可养宠物、到期优先续租、可办居住登记）全部写进合同。
- [ ] 一式两份签字按手印，自己留原件；留存甲方身份证复印件与房产证复印件。

## 四、入住后与退租时（留痕自保）

- [ ] 入住当天全屋录像+拍照存档并云端备份，作为退租验收基准。
- [ ] 条件允许立即换锁芯/改密码（合同允许范围内）。
- [ ] 每笔转账备注用途："XX小区押金""XX年XX月房租"，不裸转。
- [ ] 明确告知房东：租期内进入房屋须提前约定，租期内使用权归承租人。
- [ ] 报修一律文字沟通留痕（微信/短信），维修前后拍照对比。
- [ ] 按时交租并保留凭证，不给对方制造违约口实。
- [ ] 续租提前 30-60 天书面确认价格与期限，"不涨租"口头承诺无效。
- [ ] 退租按合同提前期发书面通知，预约验收时间。
- [ ] 退租验收对照入住照片逐项核验，当场签署验收单，双方签字。
- [ ] 结清水电燃气费并留存缴费截图，办理居住登记/户口事项迁移。
- [ ] 押金逾期不退的处理路径：书面催告（留痕）→ 12315/住建部门投诉 → 人民调解 → 小额诉讼（标的小、成本低的维权途径）。

## 五、常见事实问答（FAQ 素材）

> 供意图 E 直答"押几付几/中介费多少"等事实性问题引用。各地各城有差异，以当地惯例与合同为准。

- 押付惯例：个人房源以押一付三为主流，押一付一次之；二线城市和房东直租可谈押一付一。长租公寓常打"押一付一"，但要重新算总成本：商水商电单价高、合同里可能藏"按年提价"条款。
- 中介费行情：通常为半个月至一个月租金；北京等地多为租客付一个月，上海等地常见租客房东各付 35%，部分城市房东付。签约前先问清谁付、能否打折。
- 退租提前通知期：通常提前 30 天书面通知，合同另有约定从其约定；提前退租一般扣一个月押金或按合同违约金条款执行，签约前先算清。
- 居住证/租房备案：办居住证需租赁备案登记（房东配合提供房产证、身份证、租赁合同），部分城市要求房东到场或网上申报；房东不配合时可凭租赁合同、转账记录等到街道咨询替代材料。
- 水电燃气过户自查：入住当天抄表并把底数写进合同或验收单（水表/电表/燃气表逐个拍照）；问清缴费方式是代缴还是自缴、燃气卡/电卡在哪，避免替上一任租客补缴欠费。
