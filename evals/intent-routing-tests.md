# 意图路由测试集 intent-routing-tests

目的：测 SKILL.md 的"输入预处理（五元组提取）+ 意图路由"两层逻辑，共 18 条，分六组：啰嗦提问五元组提取（R01 至 R05）、超大片区（R06 至 R08：整体问法不下钻、子区由数据归纳）、复合问题拆分（R09 至 R11）、模糊输入澄清与复述确认（R12 至 R15）、通勤/噪音闸门回归（R16 至 R17）、地名直达 A 与零假设/零添加（R18）。

五元组字段：标的 / 城市 / 标的类型 / 关注点 / 约束。判定时逐字段比对，字段全对且路由正确才算该条通过。

## 一、啰嗦提问：五元组提取

### R01
- input: 我最近看上了回龙观那边一个小区叫龙泽苑 中介一直推说物业便宜让我赶紧定 但我同事之前住那说物业不咋地 想租房 想知道这小区口碑到底咋样
- expected 五元组: 标的=龙泽苑；城市=北京（由回龙观推知，推不出则问）；类型=小区；关注点=口碑/物业；约束=无
- expected 路由: A，搜索词围绕"龙泽苑 租房/怎么样"组合，"中介"不是标的

### R02
- input: 杭州未来科技城的龙湖冠寓值得租吗 我和我对象明年三月去那边上班 预算五千 要一居室 看有人说全是坑有人说好 到底值不值
- expected 五元组: 标的=龙湖冠寓（未来科技城）；城市=杭州；类型=小区（公寓）；关注点=推荐/值不值；约束=预算5000/一居室/明年3月
- expected 路由: B，mode=recommend；预算与时间不进搜索词，留给过滤层

### R03
- input: 救命 下周就要去深圳报到 公司在南山区科技园 工资也就一万二 不敢合租太远又怕整租太贵 通勤单程最多40分钟吧 帮我想想住哪好
- expected 五元组: 标的=空；城市=深圳；类型=空（候选片区由采集数据归纳）；关注点=性价比；约束=通勤<=40分钟/整租或合租待定/预算未明说
- expected 路由: C；预算与合租整租偏好缺失按 C 工作流一次性问齐，然后按用户问法直接采集，候选片区由数据归纳

### R04
- input: 是这样的 我对象下个月来北京 我们想在十号线沿线找个一居室 直租 不要中介 中介费真的交不起 预算最多四千五 最好月底前能入住
- expected 五元组: 标的=空（十号线沿线是位置词）；城市=北京；类型=空；关注点=直租/无中介；约束=一居室/预算4500/月底前
- expected 路由: D，时间窗近 7 天、按最新发布排序；"十号线沿线"作为位置词组合搜索词

### R05
- input: 第一次租房啥也不懂 中介说押一付三 半个月中介费 还有什么卫生费网络费 这都正常吗 我是学生党怕被坑
- expected 五元组: 标的=空；城市=空；类型=空；关注点=押金/中介费/杂费/避坑；约束=学生
- expected 路由: E，不采集，直接读 checklist 对应阶段作答

## 二、超大片区：不下钻，子区由数据归纳

### R06
- input: 北京天通苑租房怎么样 二房东多吗
- expected 五元组: 标的=天通苑；城市=北京；类型=片区（超大）；关注点=二房东；约束=无
- expected 路由: A，整体问法**不下钻**：直接以"天通苑+场景词"当普通标的采集，帖内自然带子区信息，分析时按子区归类呈现；问子小区粒度（"住哪个区合适"）时同样直接搜回龙观，子区对比由分析层从帖内归类

### R07
- input: 回龙观住哪个区合适啊 我在上地上班 预算三千五 合租就行
- expected 五元组: 标的=回龙观；城市=北京；类型=片区（超大）；关注点=住哪个子小区；约束=上地上班/预算3500/合租
- expected 路由: B：搜索词=「回龙观+场景词」照常采集（**不枚举子小区拼搜索词**），分析层把帖内提及的各子区当对比项（数据里有几个写几个，按通勤/预算整理），信息不足明示并建议实地核验

### R08
- input: 我想了解下康城怎么样
- expected 五元组: 标的=康城；城市=缺失；类型=待判断（上海康城为超大片区，但城市未知）；关注点=泛了解；约束=无
- expected 路由: 不直接路由；先一句话问城市（一次问齐），城市确认后照常路由（超大片区也直接搜片区名，不下钻）

## 三、复合问题：拆分顺序

### R09
- input: 在国贸上班预算3000住哪合适 还有那边有没有个人转租的房源
- expected 拆分: 第一问无标的（工作地国贸+预算）归 C；第二问求转租房源归 D
- expected 顺序: C->D 依次执行：先出数据归纳的片区结论，再按片区位置与预算走 D 找房（近 7 天、最新在前）

### R10
- input: 天通苑东三区怎么样 另外第一次租房押金一般押几付几
- expected 拆分: 第一问有明确子小区标的归 A；第二问无标的押金知识归 E
- expected 顺序: A->E 依次执行；E 不采集直接读 checklist 作答

### R11
- input: 帮我查下这个中介靠谱吗 北京海淀那边的XYZ地产 另外中介费一般是谁出啊
- expected 拆分: 第一问标的是中介归 A（类型=中介，应含 collect_12315）；第二问费用知识归 E
- expected 顺序: A->E；中介标的的搜索词用"XYZ地产 靠谱吗/套路/退费"

## 四、模糊输入：反问澄清与复述确认

### R12
- input: 我想问问阳光小区怎么样
- expected 行为: 标的=阳光小区但全国重名极多、城市缺失，不瞎猜不路由；一句话反问城市（一次问齐），拿到城市后再走 A
- expected 五元组: 标的=阳光小区；城市=缺失待问；类型=小区；关注点=泛了解；约束=无

### R13
- input: 我要租房 你看着办
- expected 行为: 无标的、无城市、无预算，意图本身也判断不了；按规则反问澄清（位置/预算/整租合租/时间窗一次问齐），澄清后按答案归 C 或 D
- expected 五元组: 全字段缺失

### R14
- input: 有个叫王伟的房东要租我房子 怎么知道他靠不靠谱
- expected 行为: 标的类型=房东归 A，但人名过泛、舆情检索可行性差；先反问可标识信息（房源地址/联系电话/挂房平台），并明示对人名的公开舆情检索效果有限，不编造结论
- expected 五元组: 标的=王伟（房东）；城市=缺失；类型=中介（含房东）；关注点=房东靠谱；约束=无

### R15
- input: 预算2500到3000 合租 深圳南山 3月入住 不要一楼 要女生合租 有电梯 最好近地铁
- expected 五元组: 标的=空；城市=深圳（南山）；类型=空；关注点=合租/近地铁；约束=预算2500至3000/3月入住/女生合租/电梯房/非一楼
- expected 路由: 信息密集但清晰，先一句话复述确认（例："深圳南山合租女生间，预算2500到3000，3月入住，要电梯房不碰一楼，对吗？"），确认后走 D；约束不进搜索词

### R16（通勤闸门回归）
- input: 望京西的红庭小区怎么样 想知道坑点
- expected 行为: 走 A；顺带问通勤目的地但用户不答 → 不跑 route、不做任何到工作地的通勤测算，analysis.coverage.note 不写「通勤目的地：」，报告无通勤块、地图不画通勤线；标的自身交通配套仍可从帖子内容评估并标注"未实地验证"
- expected 五元组: 标的=红庭小区；城市=北京（望京西）；类型=小区；关注点=口碑/坑点；约束=无

### R17（噪音闸门回归）
- input: 帮我看看朝阳大悦城附近的世纪社区 租房靠谱吗 顺便这附近晚上吵不吵
- expected 行为: 走 A/B；用户明确问了"晚上吵不吵" → 地理层应跑 noise 查询（这是 noise 的唯一触发路径）；若用户没主动问噪音，默认只跑 geocode+around 配套，不跑 noise
- expected 五元组: 标的=世纪社区；城市=北京（朝阳大悦城附近）；类型=小区；关注点=口碑/噪音；约束=无

## R18：地名+租房直达 A（零候选/零添加/零假设）

- input: 海淀永丰租房
- expected 行为: 走 A（片区级标的），直接搜"永丰 租房体验/口碑"类关键词；不生成候选片区、搜索词不加地铁站/16号线/合租单间等用户未说的限定词、不默认假设合租单间
- expected 五元组: 标的=永丰；城市=北京（海淀锚点）；类型=片区；关注点=口碑/租房；约束=无（未指定，不猜）

## 判定口径

- 每条 10 分：五元组 5 字段各 1 分，路由/动作（含拆分顺序、澄清行为、超大片区处理）5 分
- 建议通过线：总分不低于 144/180，且 R09 至 R11 拆分顺序与 R12 至 R14 澄清行为零错误（这两类错会直接跑偏工作流）；R16/R17 闸门行为零错误（通勤/噪音闸门破了会直接产出捏造内容）
