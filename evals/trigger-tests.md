# 触发测试集 trigger-tests

目的：验证 SKILL.md frontmatter description 的触发率与边界。共 30 条：正例 25 条（中文口语，五意图 A/B/C/D/E 各 5 条），负例 5 条（不应触发的近邻问题，全中文）。

用法：逐条把"用户原话"原样贴进新会话（不要加"请用租房 skill"等引导词，否则测不出 description 触发），观察是否触发 rent-assist，并在"结果"列打钩。统计方法见 README.md。

标注说明：
- expected_intent 取值：A 小区综合了解 / B 推荐评价 / C 选址建议 / D 找转租房源 / E 租房咨询 / NOT_RENTAL 不应触发。
- 复合问题标成 "A->E" 这类形式，指拆分后依次执行的顺序。

## 统计口径

- 触发率 = T01 至 T25 中触发条数 / 25
- 误触发数 = T26 至 T30 中触发条数（目标为 0）
- 意图正确率 = expected_intent 判对条数（含拆分顺序）/ 25
- 建议通过线：触发率不低于 90%，误触发为 0，意图正确率不低于 85%；不达标先改 description 再回归
